clircs version history

This records meaningful development builds. The early preview series is grouped by milestone where the surviving packages do not justify pretending every minor preview deserves a novel.

v0.8.0 through v0.8.61

DCC and direct-transfer milestone. Built one typed request, state, and lifecycle system for DCC CHAT and SEND; incoming and outgoing active and passive connections; IPv4 and IPv6 offers; progress, cancellation, collision-safe downloads, and resumable transfers; TLS-based SCHAT and SSEND without plaintext fallback; and interactive XDCC and secure XDCC pack requests. DCC sockets, listeners, files, timers, buffers, and background work gained explicit ownership, integrity checks, legal state transitions, and coordinated cleanup.

Architecture and audit milestone. Audited and rebuilt IRC protocol compatibility, response routing, connection and reconnect lifecycles, persistent configuration, command and help ownership, terminal windows, presentation, scripting, userlist and protection behavior, and application concurrency. Split the former 11,622-line `ClientApplication` source into domain partials, then moved durable runtime state into dedicated session, DCC, routing, window, synchronization, transient-state, policy, and preference owners. Stateful numeric families gained focused processors, stable IDs and negotiated IRC case mapping became authoritative, and the inbound application pipeline became an explicit ordered set of inspectable stages.

Resilience, authentication, and security milestone. Replaced visible inbound flood suppression with ordered lossless event delivery, batched terminal presentation, asynchronous logging, ring-buffer scrollback, and explicit emergency resource boundaries. Added bounded outbound scheduling and automatic CTCP reply limits separately from personal and channel protection. Added IRCv3 CAP negotiation, SASL PLAIN and EXTERNAL over TLS, Windows-protected credentials, structured channel list modes, MONITOR with ISON fallback, raw network debug windows and logging, responsive semantic tables and hyperlinks, traditional IRC input and topic formatting, asynchronous DNS cancellation, and terminal sanitization for hostile control and bidirectional text.

v0.7.0 through v0.7.6

Compatibility milestone. Server capabilities advertised through numeric 005 became connection-specific state instead of fixed ratbox assumptions. Added and corrected formatting for major IRCd families, WHO, WHOIS, WHOWAS, LIST, forwarding, account and hidden-host numerics, notices, and traditional IRC colors. Slow registrations gained a 60-second timeout. Reconnect cancellation, query behavior, and cross-network window handling were tightened during real-network testing.

v0.6.0 through v0.6.2

Scripting milestone. Added JavaScript addon loading through Jint, permissions, command registration, scoped events, private persistent storage, encrypted script secrets, remembered load state, and runtime limits. The musikcube example proved that a script could control an external program and contribute display content without adding musikcube-specific behavior to the core client.

v0.5.0 through v0.5.13

Connectivity and persistence milestone. Added automatic reconnect with intentional, accidental, and KILL-aware behavior; saved connection routes and credentials; ZNC awareness; preserved windows across disconnects; network profiles; safer configuration writes and backups; daily logging; per-window input history; DNS lookup; and numerous connection-state corrections found through extended use.

v0.4.19 through v0.4.25

Terminal and protection milestone. Added the full-screen redrawable viewport, stable numbered windows, status and topic bars, unread activity, themes, formatted WHO and WHOIS output, channel and personal protection, userlists, clone detection, network-scoped channel settings, settings help, and the current command-oriented interface.

v0.3 development series

Established the standalone IRC client: Windows console input, server connections, TLS certificate handling, multiple network sessions, channels and queries, core convenience aliases, local echo behavior, autojoin profiles, membership state, basic formatted server output, and early theming. The project was renamed from WircN to clirc and then to clircs during this period.

M0 through M2 prototypes

Proved the architecture, command parser, network session isolation, protocol framing, and basic ability to connect, join, and chat. These builds were working prototypes rather than public releases.
